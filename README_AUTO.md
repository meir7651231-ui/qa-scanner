# בדיקת חשיפה אוטומטית — הרצה על המחשב שלך

מערכת שרצה לבד, סורקת רשימת אתרים, ומכינה דוח PDF לכל אחד + סיכום מדורג
(מי הכי חשוף). מבוססת על 116 בדיקות של מידע ציבורי בלבד.

> ⚠️ **חשוב:** הריצו את זה **על המחשב שלכם**, לא בענן. בענן יש פרוקסי שחוסם
> גלישה לאתרים זרים וסריקה מרובה. על המחשב שלכם הכל עובד, כולל נגישות אמינה.
>
> ⚠️ **אמתו כל ממצא בעיניים לפני פנייה ללקוח.** הכלי מצמצם טעויות, לא מבטל אותן.
> הריצו על **רשימה ממוקדת** של עסקים (לא סריקה המונית אקראית של זרים).

## התקנה (פעם אחת)

צריך Python 3.9+ מותקן. ואז בטרמינל, בתיקיית הפרויקט:

```bash
pip install requests beautifulsoup4 lxml playwright
python -m playwright install chromium
```

## שימוש

1. ערכו את `sites.txt` — דומיין אחד בכל שורה (שורה שמתחילה ב-# היא הערה):
   ```
   karo.co.il
   example-store.co.il
   ```
2. הריצו:
   ```bash
   python auto_audit.py sites.txt
   ```
3. התוצאות ב-`reports/`:
   - `reports/_SUMMARY.html` — טבלה מדורגת, מי הכי חשוף למעלה. **פתחו את זה קודם.**
   - `reports/<אתר>.pdf` — דוח מלא ומעוצב לכל אתר, לשליחה ללקוח.

## שיירוץ לבד (כמו הבוט)

### Mac / Linux (cron)
לרוץ כל יום ב-03:00:
```bash
crontab -e
# הוסיפו שורה (החליפו את הנתיב בנתיב האמיתי):
0 3 * * * cd /path/to/qa_scanner && /usr/bin/python3 auto_audit.py sites.txt >> reports/log.txt 2>&1
```

### Windows (Task Scheduler)
1. פתחו "Task Scheduler" → "Create Basic Task".
2. Trigger: Daily, בשעה שתבחרו.
3. Action: Start a program →
   - Program: `python`
   - Arguments: `auto_audit.py sites.txt`
   - Start in: הנתיב לתיקיית `qa_scanner`.

בבוקר יחכו לכם הדוחות ב-`reports/`.
