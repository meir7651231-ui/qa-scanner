# Roadmap

<a id="עברית"></a>
## עברית

**הפרויקט קפוא מ־6 בנובמבר 2026. אין תוכנית פיתוח.**

- הקוד נשאר כפי שהוא, וה־CI על `main` ממשיך לרוץ.
- אין גרסאות חדשות מתוכננות, ואין התחייבות לתקן באגים.
- דיווחים עדיין מתקבלים ([CONTRIBUTING.md](CONTRIBUTING.md)); ייתכן שיטופלו אם הפרויקט יופשר.
- הפשרה תהיה החלטה של בעל הריפו, ותירשם כאן וב־[CHANGELOG.md](CHANGELOG.md).

<a id="english"></a>
## English

**The project has been frozen since November 6, 2026. There is no development plan.**

- The code stays as it is, and CI on `main` keeps running.
- No new versions are planned, and there is no commitment to fix bugs.
- Reports are still welcome ([CONTRIBUTING.md](CONTRIBUTING.md)); they may be handled if the project is unfrozen.
- Unfreezing is the repository owner's decision, and will be recorded here and in [CHANGELOG.md](CHANGELOG.md).
